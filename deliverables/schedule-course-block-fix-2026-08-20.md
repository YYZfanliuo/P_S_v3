# 课程色块显示修复

## 问题
在课程表中设置了星期、开始时间和结束时间后，进入日程管理时，课程没有显示为日程色块。此前日程视图只读取 `data.schedule`，而课程记录保存在 `data.timetable`，两者没有合并到渲染层。

## 修复
- 新增按日期生成统一事件列表的逻辑 `scheduleEventsForDate(dateValue)`。
- 日视图、周视图、月视图统一读取已有日程和固定课程。
- 课程按照星期、开学日期对应的学期周次、起止周、单双周和自定义周次过滤。
- 课程色块使用独立的 `course-{课程ID}-{日期}` 标识，不会写入或复制成普通日程。
- 点击普通日程仍打开日程编辑器；点击课程色块打开课程编辑器。
- 桌面端 `scripts/app.js` 与发布端 `www/scripts/app.js` 已同步。

## 验证
- 两端 JavaScript 均通过 Node 语法检查。
- `git diff --check` 通过。

## 使用说明
1. 在“我的课程表”中设置课程星期、开始时间、结束时间和有效周次。
2. 在“日程管理”切换到日视图或周视图。
3. 对应日期会显示课程色块；若没有显示，先检查课程星期与学期起始日期、起止周设置。
