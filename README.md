# 个人工作台

这是一个个人日常管理 App 与桌面端 Web 项目。

完整的跨平台交接信息请阅读 [`项目交接说明.md`](项目交接说明.md)，手机端使用方法请阅读 [`手机App使用文档.html`](手机App使用文档.html)。

## 项目入口

- GitHub Pages 桌面端：<https://yyzfanliuo.github.io/P_S_v3/>
- GitHub Pages 移动端：<https://yyzfanliuo.github.io/P_S_v3/www/mobile.html>
- GitHub 仓库：<https://github.com/YYZfanliuo/P_S_v3>

## 快速开始

```powershell
npm install
npm run dev
```

Android 构建：

```powershell
npm run build:android
```
