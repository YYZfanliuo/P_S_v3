# 项目长期约定

- 用户不懂编程语言。遇到功能性问题时，先用非技术语言说明：现象、影响、可能原因、候选方案和取舍，等待用户确认达成合意后再修改代码或修复。
- 遇到 UI 问题，或需要用户提供可通过学习获得的元素信息时，先提供可直接填写的中文信息模板/填空框，帮助用户描述页面位置、元素内容、期望效果、参考样式和限制条件；不要要求用户使用代码术语。
- 产品方向和交互取舍必须先分析并达成合意；无须确认的检查、同步和汇报可持续推进。
- 当前阶段暂缓商业化，不把商业化作为近期开发目标；优先推进 PC 端 AI 功能，先验证个人工作台的智能判断与建议价值。
- AI 接入方式由用户自行提供服务和接口资料，仅在用户自己的电脑本地使用；用户希望通过自定义模型配置面板自行填写接口信息，暂时允许 AI 接收完整工作台数据，用户自己负责 API 配置，不需要助手索取密钥或绑定具体服务。
- 当前处于开发者使用与调试阶段，新增调试功能时优先完整记录运行现场，不提前引入加密、脱敏、生产环境、其他版本兼容或商业化约束；运行日志当前先聚焦 PC 开发环境。
